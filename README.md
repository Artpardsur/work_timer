# ⏱️ Work Timer — перерывы, разминка и напоминания моргать

[![Python](https://img.shields.io/badge/python-3.9%2B-blue)](https://www.python.org/downloads/)
[![Зависимости](https://img.shields.io/badge/зависимости-нет-brightgreen)]()
[![License](https://img.shields.io/badge/license-MIT-yellow)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-13%20passed-brightgreen)]()

Программа для тех, кто за компьютером забывает встать и перестаёт моргать.
Отсчитывает рабочие отрезки, вовремя выгоняет на разминку, считает
отработанное время и ведёт историю по дням.

```
 ┌──────────────────────────────────────────┐
 │              ▶ Работа                    │
 │                                          │
 │                24:17                     │
 │   ████████████████░░░░░░░░░░░░░░░░░░     │
 │                                          │
 │   👁 Моргните — посмотрите вдаль 20 с    │
 │                                          │
 │  [▶ Старт] [⏸ Пауза] [⏹ Стоп] [⏭ …]     │
 └──────────────────────────────────────────┘
```

## ✨ Возможности

- **Рабочие отрезки и перерывы** по кругу: 30 минут работы → 5 минут отдыха
- **Напоминания моргать** каждые 10 минут — глаза за экраном моргают втрое реже
- **Честная пауза** — время паузы не попадает в отработанное
- **Учёт времени и история по дням** — сколько отработано вчера, позавчера
- **Два интерфейса**: окно (`gui_app.py`) и консоль (`main.py`)
- **Никаких зависимостей** — только то, что уже есть в Python

## ⚙️ Установка и запуск

Нужен только Python 3.9 или новее — сторонние библиотеки не требуются.

```bash
git clone https://github.com/Artpardsur/work_timer.git
cd work_timer

python gui_app.py     # оконная версия
python main.py        # консольная версия
```

### Консольные команды

| Клавиша | Действие |
|---|---|
| `p` | пауза / продолжить |
| `s` | стоп / старт заново |
| `r` | отчёт по дням |
| `h` | справка |
| `q` | выход |

## ⚙️ Настройки

Задаются прямо в окне и запоминаются между запусками. Значения могут быть
дробными: `0.5` — это тридцать секунд, удобно, чтобы проверить, не дожидаясь
получаса.

| Настройка | По умолчанию |
|---|---|
| Перерыв каждые | 30 минут |
| Моргать каждые | 10 минут |
| Длительность перерыва | 5 минут |

Настройки и история лежат в `%LOCALAPPDATA%\WorkTimer\` — не в папке
программы, поэтому переустановка их не сотрёт.

> **О звуке.** `sounds/blink.wav` длится 36,8 секунды — это не короткий
> сигнал, а целый фрагмент. Каждые десять минут такое утомляет, поэтому по
> умолчанию напоминание о моргании — короткий системный звук. Длинный
> включается галочкой в настройках.

## 🧱 Структура

```text
work_timer/
├── main.py             # запуск консольной версии
├── gui_app.py          # оконная версия
├── WorkTimer.spec      # рецепт сборки exe (PyInstaller)
├── src/
│   ├── timer.py        # двигатель: фазы, пауза, статистика
│   ├── notify.py       # звук и текст напоминаний
│   └── storage.py      # настройки и история по дням
├── ui/
│   └── console_ui.py   # консольный интерфейс
├── tests/
│   └── test_timer.py   # 13 проверок на подставных часах
└── sounds/             # звуки напоминаний
```

Двигатель в `src/timer.py` не знает ни про окно, ни про консоль и не создаёт
потоков: время двигается вызовом `tick()`, а интерфейс сам решает, как часто
его звать — из `root.after` или из своего цикла.

## 🧪 Тесты

```bash
pip install pytest
python -m pytest
```

Часы в тестах подставные, поэтому рабочий день прогоняется за миллисекунды —
проверяются пауза, границы фаз, накопление статистики и то, что частота
опроса не меняет результат.

## 📦 Сборка exe

```bash
pip install pyinstaller
pyinstaller WorkTimer.spec
```

Результат — `dist/WorkTimer.exe`, звуки лежат внутри.
